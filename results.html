01 · Statistical mechanics · Bayesian

Bayesian inference on the 2D Ising model

Simulate a lattice of spins with Metropolis Monte Carlo, then infer the critical temperature and critical exponent with MCMC — validated against the exact Onsager (1944) solution.

Tc = 2.371 ± 0.034
critical temperature · Onsager exact 2.2692; the upward shift is the finite-size effect on a 32×32 lattice
β = 0.093 ± 0.023
critical exponent · the 95% HDI brackets the exact universal value 1/8 = 0.125
R̂ ≤ 1.03
Gelman-Rubin across all parameters — the sampler converged

02 · Deep learning · Dynamical systems

Neural ODEs with a Hamiltonian prior

Learn the right-hand side of conservative ODEs from short noisy trajectories. A Hamiltonian Neural Network encodes the symplectic structure, so it conserves the invariant H by construction where an unconstrained MLP drifts (5-seed error bars).

9.0 ± 3.3 % → 2.4 %
invariant-H drift on Lotka-Volterra · unconstrained MLP → Hamiltonian NN, same parameter budget
0.96 ± 0.57 %
relative extrapolation error past the training window (Lotka-Volterra baseline)
8.3 ± 2.4 %
relative extrapolation error on the damped pendulum (baseline)

03 · Deep learning · MLOps

Reconstruction-based anomaly detection · CMAPSS

An LSTM autoencoder trained on healthy turbofan windows from NASA CMAPSS FD001; the reconstruction error becomes the anomaly score, with the threshold fixed as the 99th-percentile of the healthy validation error. Served as a typed FastAPI service, a Streamlit demo and a two-service Docker stack.

ROC-AUC 0.969
the score alone ranks anomalous windows above healthy ones almost perfectly
F1 0.738
at the calibrated threshold · recall 0.937 at precision 0.608
PR-AUC 0.882
precision-recall area · robust to the 15.8% anomaly class imbalance
